# Decisiones

Registro corto. Una fila por decisión. Si una decisión cambia, se añade otra fila; no se reescribe
la historia.

| Fecha | Decisión | Motivo |
| --- | --- | --- |
| 2026-11-15 | Eliminar `specs/` y reconstruir la documentación en `docs/`. | El material anterior era caótico y difícil de mantener. |
| 2026-11-15 | Mantener el nombre neCyberWiki, pero presentarlo como archivo personal de aprendizaje. | “Wiki” promete cobertura; el valor real está en el criterio y la curaduría. |
| 2026-11-15 | Añadir buscador estático al MVP con Pagefind. | Un archivo consultable necesita búsqueda; no requiere backend. |
| 2026-11-15 | Mantener ocho categorías y encender solo las que tienen contenido. | La taxonomía da dirección, pero no debe aparentar contenido inexistente. |
| 2026-11-15 | Mostrar primero las categorías disponibles y después las de hoja de ruta. | Evita que la portada del catálogo parezca un proyecto vacío. |
| 2026-11-15 | Bandit pasa a ser curso de Linux y Sistemas. | Su intención es enseñar terminal desde cero, no ser un archivo de writeups. |
| 2026-11-15 | Rutas de curso anidadas: `/cursos/<categoria>/<curso>/`. | La categoría deja de ser un adorno y ordena la navegación. |
| 2026-11-15 | Eliminar la sección Notas. | Bandit se integra en cursos; el resto no aportaba una sección propia. |
| 2026-11-15 | Eliminar certificados y comentarios. | No hay backend ni emisión real; mantenerlos generaba expectativas falsas. |
| 2026-11-15 | Bitácora pública en `/bitacora/`, con redirección desde `/blog/`. | El nombre visible y la URL deben coincidir. |
| 2026-11-15 | Roadmap público en `/roadmap/` con estados, sin fechas prometidas. | Transparencia sin convertir el proyecto en una promesa de calendario. |
| 2026-11-15 | Ko-fi como enlace simple, sin widget ni sync automática. | Evita JS de terceros y métricas inventadas. |
| 2026-11-15 | Comunidad de YouTube como bloque enlazado, sin incrustar videos. | Prioriza rendimiento y moderación; el canal sigue siendo el espacio de conversación. |
| 2026-11-15 | Candado legal bloqueante en la primera visita. | El uso educativo y legal debe aceptarse antes de navegar. |
| 2026-11-15 | Eliminar la prohibición de redistribución del texto legal. | El foco es el uso legal y educativo; se invita a apoyar el proyecto. |
| 2026-11-15 | Perfil local mínimo con exportar, importar y borrar JSON. | Da control de datos sin cuentas ni backend. |
| 2026-11-15 | Flujo 10 + 5 solo para cambios grandes. | Evitar burocracia en arreglos pequeños. |
| 2026-11-15 | El botón de búsqueda y el perfil viven en el header; “Empezar” desaparece. | El header debe representar el sitio completo, no solo el curso de Arch. |
