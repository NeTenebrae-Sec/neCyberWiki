# Decisiones

Registro corto. Una fila por decisión. Si una decisión cambia, se añade otra fila; no se reescribe
la historia.

| Fecha      | Decisión                                                                                  | Motivo                                                                                                               |
| ---------- | ----------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 2026-11-15 | Eliminar `specs/` y reconstruir la documentación en `docs/`.                              | El material anterior era caótico y difícil de mantener.                                                              |
| 2026-11-15 | El aviso legal se vuelve bloqueante salvo en `/terminos/`.                                | Escape, cierre o backdrop no cierran el gate; el botón acepta y guarda la fecha.                                     |
| 2026-11-15 | El perfil local se implementa con lógica pura y exportación/importación validada.         | Los datos viven en `localStorage`; el JSON versionado permite mover el perfil.                                       |
| 2026-11-15 | El drawer destaca el curso actual de la ruta, no siempre el primero.                      | El progreso continuo debe corresponder a dónde está el lector.                                                       |
| 2026-11-15 | Mantener el nombre neCyberWiki, pero presentarlo como archivo personal de aprendizaje.    | “Wiki” promete cobertura; el valor real está en el criterio y la curaduría.                                          |
| 2026-11-15 | Añadir buscador estático al MVP con Pagefind.                                             | Un archivo consultable necesita búsqueda; no requiere backend.                                                       |
| 2026-11-15 | Mantener ocho categorías y encender solo las que tienen contenido.                        | La taxonomía da dirección, pero no debe aparentar contenido inexistente.                                             |
| 2026-11-15 | Mostrar primero las categorías disponibles y después las de hoja de ruta.                 | Evita que la portada del catálogo parezca un proyecto vacío.                                                         |
| 2026-11-15 | Bandit pasa a ser curso de Linux y Sistemas.                                              | Su intención es enseñar terminal desde cero, no ser un archivo de writeups.                                          |
| 2026-11-15 | Rutas de curso anidadas: `/cursos/<categoria>/<curso>/`.                                  | La categoría deja de ser un adorno y ordena la navegación.                                                           |
| 2026-11-15 | Eliminar la sección Notas.                                                                | Bandit se integra en cursos; el resto no aportaba una sección propia.                                                |
| 2026-11-15 | Eliminar certificados y comentarios.                                                      | No hay backend ni emisión real; mantenerlos generaba expectativas falsas.                                            |
| 2026-11-15 | Bitácora pública en `/bitacora/`, con redirección desde `/blog/`.                         | El nombre visible y la URL deben coincidir.                                                                          |
| 2026-11-15 | Roadmap público en `/roadmap/` con estados, sin fechas prometidas.                        | Transparencia sin convertir el proyecto en una promesa de calendario.                                                |
| 2026-11-15 | Ko-fi como enlace simple, sin widget ni sync automática.                                  | Evita JS de terceros y métricas inventadas.                                                                          |
| 2026-11-15 | Comunidad de YouTube como bloque enlazado, sin incrustar videos.                          | Prioriza rendimiento y moderación; el canal sigue siendo el espacio de conversación.                                 |
| 2026-11-15 | Candado legal bloqueante en la primera visita.                                            | El uso educativo y legal debe aceptarse antes de navegar.                                                            |
| 2026-11-15 | Eliminar la prohibición de redistribución del texto legal.                                | El foco es el uso legal y educativo; se invita a apoyar el proyecto.                                                 |
| 2026-11-15 | Perfil local mínimo con exportar, importar y borrar JSON.                                 | Da control de datos sin cuentas ni backend.                                                                          |
| 2026-11-15 | Flujo 10 + 5 solo para cambios grandes.                                                   | Evitar burocracia en arreglos pequeños.                                                                              |
| 2026-11-15 | El botón de búsqueda y el perfil viven en el header; “Empezar” desaparece.                | El header debe representar el sitio completo, no solo el curso de Arch.                                              |
| 2026-11-15 | Bandit se migra de `content/notas/bandit/` a `content/cursos/bandit/`.                    | Un curso necesita una colección, un manifiesto y un temario, no una carpeta de notas.                                |
| 2026-11-15 | Bandit se divide en cuatro módulos: primeros pasos, búsqueda, texto y red.                | Da estructura didáctica a 19 niveles que antes eran una lista plana.                                                 |
| 2026-11-15 | Bandit conserva `orden` 0–18; Arch usa 0–7 y suma 1 al mostrar.                           | La interfaz debe respetar la numeración real de cada curso.                                                          |
| 2026-11-15 | El manifiesto declara `unidad: "clase"` o `"nivel"`.                                      | Evita deducir la etiqueta desde el slug o desde el número de lecciones.                                              |
| 2026-11-15 | La disponibilidad de una categoría se deriva de sus cursos publicados.                    | Una categoría vacía no debe fingir contenido ni exigir mantenimiento manual.                                         |
| 2026-11-15 | Las imágenes de Bandit pasan a `/cursos/bandit/` y los redirects incluyen la base.        | Las rutas antiguas siguen funcionando sin generar enlaces relativos rotos.                                           |
| 2026-11-15 | `npm run import:bandit` genera el curso completo desde el archivo de Obsidian.            | La reimportación debe producir el mismo esquema que consume el sitio.                                                |
| 2026-11-16 | Usar los componentes oficiales de Pagefind en lugar de una UI propia.                     | `PagefindUI` ya no está expuesto por `pagefind-component-ui.js`; los componentes mantienen dropdown y accesibilidad. |
| 2026-11-16 | Dos instancias Pagefind (`header` y `page`) con `bundle-path` explícito.                  | Los módulos no detectan el subpath `/neCyberWiki/`; cada instancia necesita su ruta.                                 |
| 2026-11-16 | El buscador del header solo se muestra desde 1100 px; el icono lleva a `/buscar/`.        | Evita overflow y mantiene la búsqueda completa accesible en pantallas pequeñas.                                      |
| 2026-11-16 | Generar el índice con `postbuild` y no versionar `public/pagefind/`.                      | Un índice viejo servido como estático ocultaba errores y duplicaba el build.                                         |
| 2026-11-16 | Las páginas `noindex` omiten `data-pagefind-body`, no solo añaden `data-pagefind-ignore`. | Pagefind indexa cualquier página con el atributo body; `ignore` no lo anula.                                         |
| 2026-11-16 | Playwright MCP se configura solo en `.opencode/` y se ignora en git.                      | Verificación real sin tocar la configuración global ni añadir dependencias al sitio.                                 |
